PyEvoMotion documentation
=========================

Welcome to PyEvoMotion's documentation.

PyEvoMotion is a Python tool designed to assess the evolutionary dynamics of related DNA sequences. It allows researchers to analyze how mutations accumulate over time and determine whether the evolution follows standard diffusion or anomalous diffusion models.

For a quick overview of the project, check out the :ref:`overview` section.

For getting started with PyEvoMotion, see the :ref:`usage_guide` section.


The Rust implementation behind the module is documented separately with
rustdoc at `rustdoc/ <rustdoc/>`_.
